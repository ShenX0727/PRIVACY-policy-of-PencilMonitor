Getting started

开始之前

Before you start

需要 iPadOS 26.0 或更高版本，仅支持 iPad。传感器相关的功能都需要一支 Apple Pencil； 部分体检项目还需要特定型号，具体见下面的「为什么有些体检项目找不到」。

iPadOS 26.0 or later, iPad only. All sensor features need an Apple Pencil, and some tests additionally need a specific model — see “Why is a test missing from the menu?” below.

模拟器无法模拟 Apple Pencil，也没有触觉反馈。所有传感器与体检功能都必须在真机上验证。

The Simulator cannot emulate an Apple Pencil and has no haptics. Every sensor and test feature has to be verified on real hardware.

连接与识别

Connection & model

笔没被认出来

When the pencil is not recognised

系统没有开放配对状态接口，应用里的「已检测到」指的是本次会话收到过笔的事件 ——一次笔尖触摸，或一次悬停。所以打开应用后先用笔在屏幕上点一下，状态才会亮起。

如果点了还是没反应，依次检查：

  • 「设置 → Apple Pencil」里笔是否已配对、是否有电
  • 笔尖是否拧紧，屏幕保护膜是否过厚
  • 是不是第三方笔——部分第三方笔不回报压力等信号
  • 开发者模式里的「信号屏蔽」开关是否被打开过

iPadOS exposes no pairing-status API. “Detected” in the app means the app has received a pencil event in this session — one tip touch, or one hover. So tap the screen once with the pencil after launching; the status lights up then.

If tapping changes nothing, check in order:

  • Settings → Apple Pencil: is the pencil paired, and does it have charge?
  • Is the tip screwed on tight, and is the screen protector very thick?
  • Is it a third-party stylus? Some report no pressure or other signals.
  • Are any of the “signal masking” switches in developer mode still on?

系统同样不提供断开信号。应用只能知道「收到过」，无法知道「已断开」，因此该状态一旦为真 就不再改变，直到下次重新启动应用。这是接口限制，不是显示错误。

The system provides no disconnect signal either. The app can only know that events have arrived, never that the pencil has gone away, so once the status is true it stays true until the next launch. That is an API limitation, not a display bug.

系统没有型号查询接口，应用只能按收到的独占信号往回推：轻捏与侧旋指向 Pro，双击指向 二代或 Pro，悬停指向二代 / USB-C / Pro，笔尖压力可以排除 USB-C 与部分第三方笔。 信号没触发过，推断自然就保守。

在概览页工具栏的「Pencil 类型」里可以手动指定型号，指定后所有页面按该型号显示。

There is no model-lookup API. The app infers backwards from the signals it has seen: squeeze and barrel roll mean Pro; double-tap means 2nd generation or Pro; hover means 2nd generation, USB-C or Pro; tip pressure rules out USB-C and some third-party styluses. If a signal never fires, the guess stays conservative.

You can set the model by hand under “Pencil type” in the dashboard toolbar; every screen then follows that choice.

硬件体检

Hardware tests

体检项目与结果

Tests and results

当前组合不支持的项目不会显示，避免做无意义的测试。各项的前置条件是：

  • 悬停检测——笔与 iPad 双方都要支持悬停
  • 触觉反馈测试——Apple Pencil Pro
  • 挤压（轻捏）——Apple Pencil Pro
  • 双击——第二代及以后

另外，「压力 · 倾角 · 旋转」的标题会随该型号实际拥有的通道改写，缺少的通道不会出现。

Tests that the current combination cannot run are hidden rather than shown greyed out. The requirements are:

  • Hover — both the pencil and the iPad must support it
  • Barrel haptics — Apple Pencil Pro
  • Squeeze — Apple Pencil Pro
  • Double-tap — 2nd generation or later

The “pressure · tilt · roll” test also renames itself to the channels your model actually has; missing channels are left out.

悬停跟芯片代数无关，不能按新旧推断——iPad mini（A17 Pro）支持，而 iPad Air（第 5 代，M1） 不支持。应用以苹果官方的 Apple Pencil 兼容性文档为准：iPadOS 26 支持的 29 款机型中， 只有 8 款具备悬停。

Hover does not follow chip generation, so it cannot be inferred from how new the iPad is — iPad mini (A17 Pro) has it, while iPad Air (5th generation, M1) does not. The app follows Apple's own Apple Pencil compatibility document: of the 29 models supported by iPadOS 26, only 8 have hover.

先确认笔尖正接触屏幕——笔身触觉只有在接触时才会触发，悬空点按不算。

系统开放给应用的笔身触觉只有「对齐」与「路径完成」两种，不支持自定义强度、时长与波形， 系统也不回报马达是否真的动作。因此报告里这一项标记为主观结论，需要你自己 判断有没有感觉到。

First make sure the tip is touching the screen — barrel haptics only fire on contact, not in mid-air.

The system exposes exactly two barrel haptics, “alignment” and “path completed”, with no control over strength, duration or waveform, and it never reports whether the motor actually moved. That is why the report marks this item as a subjective result — the judgement is yours.

评级衡量的是本次测试里各通道覆盖到的量程范围，不是硬件的绝对好坏。 如果只是轻轻划了几笔，压力没到过最重、笔没放到过很平、也没转过一整圈，覆盖率自然偏低。

重测一次，刻意走满每个通道的两端：从最轻压到最重、从竖直压到接近贴平、把笔转满一圈。 若充分覆盖后仍有明显缺口，才值得怀疑硬件。

The grade measures how much of each channel's range you covered during that run, not the absolute health of the hardware. A few light strokes that never reach full force, never tilt the pencil flat and never roll it a full turn will score low by construction.

Run it again and deliberately hit both ends of every channel: lightest to heaviest, upright to nearly flat, a full rotation. Only a gap that survives thorough coverage is worth suspecting the hardware for.

画板与实时数据

Canvas & live data

自己动手验证

Checking it yourself

画板里的笔身手势由 PencilKit 原生处理，行为完全跟随「设置 → Apple Pencil」中的偏好： 轻捏呼出情境面板、双击切换工具。如果在系统设置里关掉了对应手势，画板里也不会有反应。 想看每次按压的阶段与时长，请到硬件体检的「挤压与双击」测试。

Barrel gestures on the canvas are handled natively by PencilKit and follow your preferences in Settings → Apple Pencil: squeeze opens the contextual palette, double-tap switches tools. If the gesture is switched off there, nothing happens here either. To see the phases and duration of each press, use the “squeeze and double-tap” hardware test.

屏幕坐标是笔尖在屏幕上的位置；按压力度归一到 0–255；倾角与方位角以弧度表示——倾角是笔与 屏幕的夹角，方位角是笔在屏幕平面上的朝向；侧旋指针对应笔身的转动角度。

这些值全部来自系统的真实事件流，并且逐帧取的是整帧采样，而不是每帧只取最后一个点。

The coordinates are the tip's position on screen; force is normalised to 0–255; altitude and azimuth are in radians — altitude is the angle between pencil and screen, azimuth is the direction it points in the screen plane; the dial shows barrel-roll angle.

All of it comes from the system's real event stream, and each frame is read as a full batch of samples rather than just its last point.

报告

Report

设备健康报告

The device health report

在概览页工具栏点「报告」生成，然后导出为文本或 PDF，用系统分享发送。建议先把想要的体检 项目跑完再生成，报告会一并收录结果。传输这一步完全由你发起，应用不参与。

Tap “Report” in the dashboard toolbar to generate it, then export as text or PDF and send it through the system share sheet. Run the tests you care about first — their results are included. The sending step is entirely yours; the app takes no part in it.

iOS 没有向第三方应用开放这些接口：设备序列号不可读，笔的电量、笔尖磨损与配对状态也都没有 公开接口。报告改用苹果官方的替代标识 identifierForVendor（IDFV）来标记设备。

iOS does not expose any of these to third-party apps: the device serial number is not readable, and there is no public API for pencil battery level, tip wear or pairing state. The report identifies the device with Apple's own substitute, identifierForVendor (IDFV), instead.

设置与数据

Settings & data

外观、重置与隐私

Appearance, reset and privacy

都在概览页工具栏的「⋯ → 外观」里：八款 App 图标、两套主题配色、深浅跟随系统或手动指定。 语言切换即时生效，不需要重启应用。

All under “⋯ → Appearance” in the dashboard toolbar: eight app icons, two colour themes, and light/dark either following the system or set by hand. Language changes take effect immediately, with no restart.

应用内提供「初始化应用」，会清空全部设置与数据，回到初装状态；也可以直接删除应用， 沙盒里的数据会一并清除。应用的数据只存在本机，删掉就没有了。

The app has a reset function that clears all settings and data back to a fresh install; deleting the app removes its sandbox contents just the same. Everything lives on the device only, so once it is gone it is gone.

不会。应用不含网络传输功能，不设账号，未接入统计分析、崩溃上报或广告组件，也不跨应用追踪。 全部读数都在本机处理与显示。完整说明见隐私政策。

No. There is no network code, no account system, no analytics, no crash reporting, no ads and no cross-app tracking; every reading is processed and shown on the device. The full statement is in the privacy policy.
