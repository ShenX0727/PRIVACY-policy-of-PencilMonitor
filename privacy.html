数据收集

Data Collection

本应用不收集任何用户数据，也没有网络传输功能——不会向开发者或 任何第三方的服务器发送数据。它不设账号体系，无需注册或登录，未接入统计分析、 崩溃上报或广告组件，也不会跨应用或跨网站追踪用户。

This application collects no user data and includes no network transmission — nothing is ever sent to the developers' servers or anyone else's. It has no account system, requires no sign-in, and integrates no analytics, crash reporting, or advertising components; nor does it track users across other apps or websites.

本地处理

Local Processing

设备检测功能会读取本机的硬件与系统信息，以及 Apple Pencil 的传感器数据；这些信息 仅在设备本地处理与显示，不会离开设备。用户可以导出检测报告，并通过 系统分享功能发送给他人——这一步完全由用户发起和控制，本应用不参与传输过程。

The diagnostic features read hardware and system information from the device, along with sensor data from Apple Pencil; this information is processed and displayed only on the device, and never leaves it. Users may export a diagnostic report and send it via the system share sheet — that step is entirely user-initiated, and the application takes no part in the transfer.

第三方共享

Third-Party Sharing

本应用不与任何第三方共享用户数据，也没有接入第三方数据服务、分析平台或广告网络。

This application shares no user data with third parties, nor does it integrate any third-party data services, analytics platforms, or advertising networks.

数据留存与删除

Data Retention and Deletion

本应用仅在设备本地存储应用内的偏好设置，数据保存在本应用自身的沙盒容器中。用户 可以通过应用内的初始化功能清除全部设置，或直接删除本应用一并清除。开发者不持有 任何用户数据，因此也没有需要用户另行申请删除或撤回授权的情形。

The application stores only its own in-app preferences, locally on the device and within its own sandbox container. Users can clear all settings through the in-app reset function, or simply delete the application. As the developers hold no user data, there is no separate deletion request or consent-withdrawal process to go through.
