数据收集

Data Collection

本应用不收集任何用户数据。它没有网络传输功能，不会向开发者或任何第三方的服务器发送数据。没有账号体系，无需注册或登录。没有统计分析，没有崩溃上报，没有广告组件。也不会跨应用或跨网站追踪你。

This application collects no user data. It has no network transmission code, so nothing is ever sent to the developers' servers or anyone else's. There is no account system, and no sign-up or sign-in. No analytics. No crash reporting. No advertising components. And no tracking across other apps or websites.

本地处理

Local Processing

设备检测功能会读取本机的硬件与系统信息，以及 Apple Pencil 的传感器数据。这些信息只在本机处理与显示，不会离开设备。你可以导出检测报告，用系统分享功能发给他人。这一步完全由你发起，由你控制，本应用不参与传输。

The diagnostic features read hardware and system information from the device, along with sensor data from Apple Pencil. That information is processed and displayed on the device only. It never leaves. You can export a diagnostic report and send it with the system share sheet. That step is yours to start and yours to control. The application takes no part in the transfer.

第三方共享

Third-Party Sharing

本应用不与任何第三方共享用户数据。也没有接入第三方数据服务、分析平台或广告网络。

This application shares no user data with third parties. It integrates no third-party data services, no analytics platforms, and no advertising networks.

数据留存与删除

Data Retention and Deletion

本应用只在本机存储应用内的偏好设置，数据保存在自身的沙盒容器中。你可以用应用内的初始化功能清除全部设置，也可以直接删除本应用，数据随之一并清除。开发者不持有任何用户数据，所以没有需要另行申请删除或撤回授权的情形。

The application stores only its own in-app preferences, on the device and inside its own sandbox container. You can clear every setting with the in-app reset, or simply delete the application and it all goes with it. The developers hold no user data, so there is no separate deletion request and no consent to withdraw.
